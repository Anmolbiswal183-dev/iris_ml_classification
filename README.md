# Iris Flower Classification - ML Model Comparison

## Project Overview
Building and comparing 3 machine learning models to classify Iris flowers based on their features.

## Dataset
- **Source:** Scikit-learn built-in Iris dataset
- **Samples:** 150 flower records
- **Features:** 4 (sepal length, sepal width, petal length, petal width)
- **Classes:** 3 (Setosa, Versicolor, Virginica)

## Models Trained
1. **Logistic Regression** - Best model ✅
2. **Random Forest Classifier**
3. **K-Nearest Neighbors (KNN)**
